# Дизайн YETI STREAM

Базовая система для всего проекта. Последующие задачи развивают её последовательно, без смены темы между страницами. Все числовые токены находятся в [tokens.css](tokens.css); подробные правила связаны ниже. Изменение системы должно быть явно отражено в [решениях](docs/decisions.md).

## Направление

- Жанр: modern-minimal. Характер: спокойный, технологичный, понятный.
- Тема: собственная «Графит и лёд» на заданных цветах бренда.
- Композиция продукта: постоянная боковая навигация и рабочая область с приоритетным действием. Для документов, списков и форм свои компоновки, описанные в [экранах](docs/design/screens.md).
- Параметры: DESIGN_VARIANCE 4/10, MOTION_INTENSITY 4/10, VISUAL_DENSITY 5/10. Это рабочий интерфейс с умеренной плотностью и заметной, но короткой обратной связью.
- Маркетинговые макроструктуры, hero, декоративные фото и footer-каталоги к текущему этапу не относятся. Главная `/` пока пустая.
- Референсная подача графитовая. Светлая и тёмная темы равноправны; первоначальная тема следует системе.

## Неизменные опоры

| Роль | Значение |
| --- | --- |
| Основной бренд | `#17232F` |
| Акцент бренда | `#2878C8` |
| Ледяные детали | `#DCE6ED` |
| Текст логотипа | Rubik Bold, 700, прямое начертание |
| Заголовки | Rubik, 600/700, прямое начертание |
| Интерфейс | Rubik, 400/500/600 |
| Иконки | Phosphor Regular, обычно 20 px |
| Базовый шаг | 4 px |
| Кнопка / поле | минимум 44 px по высоте |
| Радиусы | 8 px элементы, 12 px панели, 16 px диалоги |
| Переходы | 160-800 мс, суммарно не более 800 мс |

Использовать настоящие цвета из токенов; не подбирать похожие значения на глаз. Единственный декоративный акцент синий. Зелёный, янтарный и красный зарезервированы для статусов и никогда не заменяют основной CTA.

Белый `#FFFFFF` разрешён для текста на фирменной синей кнопке и исходного логотипа. Это осознанное исключение ради контраста. Фоны интерфейса используют холодные оттенки, а не чистый белый или чёрный.

## Система интерфейса

- Вкладки всегда растянуты на всю доступную ширину контейнера и делят её поровну. В каждой обязательны иконка Phosphor Regular и текстовая подпись; на узком экране подпись может переноситься.
- Переход между любыми вкладками плавный: одновременное исчезновение прежней панели и появление новой за 440 мс, без задержки действия; при reduced motion только opacity до 100 мс. Вес шрифта, размер, межстрочный интервал, отступы и границы названий одинаковы во всех состояниях, чтобы текст не дёргался. Активность показывают цвет и плавное появление индикатора. Повторные переключения прерывают текущий переход; доступность и фокус обновляются сразу.
- Заголовок страницы слева; `?` возле названия раздела, если есть полезное пояснение.
- Сначала задача и текущее состояние, затем детали. Карточка используется для самостоятельного объекта или действия, не вокруг каждого абзаца.
- Крупные числа показывают реальные данные. Нет искусственных графиков, процентов, анимированного счёта и «живых» индикаторов без источника.
- Компоненты общие для всех зон; различаются состав данных и разрешённые действия.
- На маленьком экране одна колонка, меню по кнопке, подписанные действия. Не переносить настольную таблицу целиком на узкий экран.
- Справка описывает действие и результат. В пользовательских тултипах нет внутренних ролей и технической терминологии.
- Полный логотип: [logo.svg](logo.svg) для светлой темы, [logo-dark.svg](logo-dark.svg) для тёмной без светлой подложки. Йети слева, YETI над STREAM справа; надпись Rubik Bold 700 со скруглёнными углами переведена в кривые. Это близкое воспроизведение образца, точный исходный шрифт не установлен. Отдельный знак: logo-mark.svg / logo-mark-dark.svg. Геометрия знака сохранена, тёмная версия имеет отдельную палитру. [Правила и размеры](docs/design/logo.md).

## Exports

[tokens.css](tokens.css) содержит только переносимые CSS custom properties, без компонентов, reset и подключения шрифтов. Это документационный контракт для будущей реализации. Цвета записаны в OKLCH с исходным HEX в комментарии.

Экспорт в Tailwind, DTCG или адаптер компонентной библиотеки делается в задаче выбора стека из этого единственного источника. Не поддерживать четыре вручную расходящиеся копии токенов. Никакой UI-фреймворк или платная библиотека сейчас не установлены.

## Статусы, уведомления и действия таблиц

- Каждый статус обязательно содержит иконку Phosphor Regular и видимую текстовую подпись; цвет дополняет смысл. Декоративная иконка скрыта от скринридера.
- Уведомления об успешном сохранении и завершении действия появляются снизу по центру экрана, относительно viewport, с учётом safe area. Показывать только подтверждённый результат, не красть фокус; role=status. Ошибки ввода показывать рядом с полями, не заменять их toast.
- Все кнопки действий в таблице размещать справа, в последнем столбце «Действия», и показывать только иконками. Обязательны доступное имя с действием и объектом, видимый фокус и область нажатия минимум 44 × 44 px. На узком экране действия также остаются справа. Общие кнопки таблицы располагаются справа над ней и тоже используют иконки.

## Ранняя загрузка шрифтов

Шрифты, используемые на странице, начинать загружать сразу: объявлять локальные @font-face в раннем CSS и preload нужных начертаний в head до основных стилей (as="font", правильный MIME и crossorigin). URL preload должен точно совпадать с URL в @font-face, чтобы не загружать файл дважды. Не откладывать загрузку шрифтов до прокрутки, клика, переключения вкладки или запуска JavaScript. Сохранять font-display: swap и читаемый fallback; не скрывать страницу в ожидании document.fonts.ready. Ранняя загрузка не гарантирует мгновенную готовность на медленной сети.

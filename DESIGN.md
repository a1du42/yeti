# Дизайн YETI STREAM

Базовая система для всего проекта. Последующие задачи развивают её последовательно, без смены темы между страницами. Все числовые токены находятся в [tokens.css](tokens.css); подробные правила связаны ниже. Изменение системы должно быть явно отражено в [решениях](docs/decisions.md).

## Направление

- Жанр: modern-minimal. Характер: спокойный, технологичный, понятный.
- Тема: собственная «Графит и лёд» на заданных цветах бренда.
- Композиция продукта: постоянная боковая навигация и рабочая область с приоритетным действием. Для документов, списков и форм свои компоновки, описанные в [экранах](docs/design/screens.md).
- Параметры: DESIGN_VARIANCE 4/10, MOTION_INTENSITY 4/10, VISUAL_DENSITY 5/10. Это рабочий интерфейс с умеренной плотностью и заметной, но короткой обратной связью.
- Маркетинговые макроструктуры, hero, декоративные фото и footer-каталоги к текущему этапу не относятся. Главная `/` пока пустая.
- Референсная подача графитовая. Светлая и тёмная темы равноправны; первоначальная тема следует системе.

## Неизменные опоры

| Роль | Значение |
| --- | --- |
| Основной бренд | `#17232F` |
| Акцент бренда | `#2878C8` |
| Ледяные детали | `#DCE6ED` |
| Текст логотипа | Nunito Sans ExtraBold, 800, прямое начертание |
| Заголовки | Manrope, 600/700, прямое начертание |
| Интерфейс | IBM Plex Sans, 400/500/600 |
| Иконки | Phosphor Regular, обычно 20 px |
| Базовый шаг | 4 px |
| Кнопка / поле | минимум 44 px по высоте |
| Радиусы | 8 px элементы, 12 px панели, 16 px диалоги |
| Переходы | 80-400 мс, суммарно не более 400 мс |

Использовать настоящие цвета из токенов; не подбирать похожие значения на глаз. Единственный декоративный акцент синий. Зелёный, янтарный и красный зарезервированы для статусов и никогда не заменяют основной CTA.

Белый `#FFFFFF` разрешён для текста на фирменной синей кнопке и исходного логотипа. Это осознанное исключение ради контраста. Фоны интерфейса используют холодные оттенки, а не чистый белый или чёрный.

## Система интерфейса

- Заголовок страницы слева; `?` возле названия раздела, если есть полезное пояснение.
- Сначала задача и текущее состояние, затем детали. Карточка используется для самостоятельного объекта или действия, не вокруг каждого абзаца.
- Крупные числа показывают реальные данные. Нет искусственных графиков, процентов, анимированного счёта и «живых» индикаторов без источника.
- Компоненты общие для всех зон; различаются состав данных и разрешённые действия.
- На маленьком экране одна колонка, меню по кнопке, подписанные действия. Не переносить настольную таблицу целиком на узкий экран.
- Справка описывает действие и результат. В пользовательских тултипах нет внутренних ролей и технической терминологии.
- Графический знак из logo.svg используется без изменений. Надпись YETI STREAM рядом с ним набирается Nunito Sans ExtraBold 800 через `--font-wordmark` и `--font-weight-wordmark`. На графитовых поверхностях знаку нужна светлая подложка, сохраняющая его силуэт.

## Exports

[tokens.css](tokens.css) содержит только переносимые CSS custom properties, без компонентов, reset и подключения шрифтов. Это документационный контракт для будущей реализации. Цвета записаны в OKLCH с исходным HEX в комментарии.

Экспорт в Tailwind, DTCG или адаптер компонентной библиотеки делается в задаче выбора стека из этого единственного источника. Не поддерживать четыре вручную расходящиеся копии токенов. Никакой UI-фреймворк или платная библиотека сейчас не установлены.

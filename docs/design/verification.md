Дата: 1 ноября 2026 года. Результат относится к документации, токенам и статическому визуальному листу.

- Визуальный лист показывает систему и образцы компонентов, без вымышленных метрик и работающих функций.
- Разово проверены ссылки 14 Markdown-документов и ссылки на 134 имени CSS-токенов: отсутствующих локальных файлов и неопределённых var-ссылок не найдено. Проверены SVG и JSON на корректность структуры. Постоянные тестовые скрипты не создавались.
- Уточнение логотипа: Nunito Sans ExtraBold 800 применяется только к надписи YETI STREAM. В SVG визуального листа встроено соответствующее начертание с OFL-лицензией; исходный графический знак logo.svg сохранён.
- PNG визуального листа отрендерен в Edge и просмотрен; шрифты встроены в SVG вместе с OFL-лицензиями для автономного просмотра. Этот лист не подменяет адаптивную проверку будущего приложения.

Все перечисленные пары проходят указанный минимум. Это не означает доступность любой произвольной комбинации цветов. В частности:

- Ледяной текст `#DCE6ED` на `#2878C8`: 3,60:1, не годится для обычной подписи кнопки.
- Фирменный синий текст `#2878C8` на графите: 3,50:1, не годится для обычного текста.
- Почти белый `#F7FAFC` на синей кнопке: 4,35:1, не проходит 4,5:1. Поэтому action-text имеет отдельный белый токен.
- `--color-line` является декоративным разделителем. Для обязательной границы управления предусмотрен `--color-control-border`.
- В тёмной теме основной CTA имеет контрастную action-border. Кольцо фокуса отделено от кнопки полосой текущей поверхности.
- Белый на фирменном синем имеет небольшой запас (4,55:1): нельзя уменьшать opacity или менять оттенок без нового расчёта.

## Проверка документационного комплекта

Проверить локальные Markdown-ссылки и пути изображений; каждую var-ссылку в CSS; отсутствие превышений motion-лимита в нормативных правилах; согласованность тем и названий токенов; актуальность списка открытых вопросов. Проверить, что не добавлены зависимости, приложение и автотесты.

Hallmark self-critique для спецификации: Philosophy 4, Hierarchy 4, Execution 4, Specificity 5, Restraint 5, Variety 4. Это качественная самопроверка документа, а не измерение работающего интерфейса. Неприменимые к документации проверки hero, реальной навигации и browser responsiveness не отмечаются пройденными.

| Область | Что проверить вручную |
| --- | --- |
| Основной сценарий | Действие достигает результата; возврат не теряет нужное состояние |
| Ошибка и повтор | Введённое сохранено, причина понятна, повтор не дублирует эффект |

| Адаптация | 320 / 375 / 414 / 768 / 1024 / 1440 px; длинные подписи и landscape |
| Масштабирование | Увеличение текста, zoom 200% и проверка reflow до эквивалента 320 CSS px |
| Темы | Светлая, тёмная, системная; фокус и disabled в каждой |
| Клавиатура | Tab, Shift+Tab, Escape, Enter/Space, стрелки вкладок, возврат фокуса |
| Справка | ? у названия, hover/focus/tap, текст без ролей, не исчезает во время чтения |
| Анимации | Суммарно ≤400 мс, быстрые повторные действия, reduced motion |
| Загрузка | Нет скачков геометрии, нулей вместо неизвестного и вечных skeleton |
| Тексты | Критичные условия видны; нет неподтверждённых гарантий |
| Производительность | Замер на оговорённом устройстве/сети; узкие места описаны фактически |

Проверять только применимое к изменению и связанные риски. Проверка сборки, типов и линтера допустима при наличии инструментов. Автотесты, snapshot и тестовая инфраструктура остаются отдельным отложенным этапом.

# Проверка приложения и документации

## Тестовый стенд оплаты — 2 ноября 2026 года

В `/app?tab=payment` добавлены вымышленные баланс и история, расчёт суммы и быстрые варианты; постоянная отметка «Вход выполнен» удалена из шапки. Денежные операции, API оплаты, реквизиты и автотесты не добавлялись. Typecheck и финальная production-сборка прошли; Next.js на loopback:100 перезапущен с новой сборкой.

В Chrome на https://a1d.by/app вручную проверены: открытие оплаты из аккаунта и фокус h1; расчёт 1 000 и 2 500 ₽, уведомление и неизменные баланс/история; пустая сумма с итогом «—», ошибкой и фокусом поля после первого нажатия; дробь 100,5 без округления и с ошибкой; ввод 99 → 100 и 50 001 → 50 000; восстановление через быстрый выбор. Первая проверка выполняется при отправке, затем ошибка обновляется при вводе. Это исключает сдвиг кнопки из-за появления ошибки во время blur до завершения клика. Изменение суммы убирает прежний результат расчёта и его уведомление.

Проверены ширины 320 / 375 / 414 / 768 / 1024 / 1440 CSS px: горизонтальной прокрутки нет, вкладки равной ширины (по 136,5 px на 320 px). На 320 px просмотрены светлая и тёмная темы, поле с ошибкой, переносы подписей и нижнее меню. Проверены нейтральный фокус меню без рамки и tooltip, Escape, вкладки мышью без outline, ArrowLeft/Home/End с фокусом на вкладке и видимым клавиатурным outline. После проверки восстановлены системная тема и обычный viewport. Снимок готового экрана сохранён вне репозитория.

Физическое касание, экранная клавиатура, screen reader, zoom 200% и reduced motion в браузере отдельно не проверялись. Новых анимаций стенд не добавляет; смена вкладок использует существующий crossfade и reduced-motion токены. Настоящие сохранение настроек, выход и платежи в этой задаче не выполнялись. HTML-витрина не изменялась.

## Google OAuth — 2 ноября 2026 года

Добавлены серверная конфигурация Google, кнопка только во входе, защищённый callback и строгая проверка OIDC через JWKS. Сборка и TypeScript прошли. Ручные HTTP-запросы: форма200 и содержит кнопку Google; старт200 выдаёт URL accounts.google.com с redirect_uri http://localhost:100/api/auth/callback/google, только email/profile/openid, PKCE S256, state и nonce; отмена через callback302 возвращает к форме с понятным состоянием ошибки; неподключённый Kick404. Полный вход, первый/повторный аккаунт и настройки redirect URI в Google Cloud не проверены без участия владельца Google-аккаунта. Реальные ключи сохранены только в игнорируемой .env.local.

Письма остаются в локальном Mailpit, на настоящие адреса не доставляются. В production-сборке повторно подтверждена отправка письма после обновления SMTP-библиотеки.

Пустое имя, неверная IANA-зона, 8 emoji вместо 15 символов и 129 ASCII-символов отвергаются сервером.
- Восстановление через Mailpit → обмен ссылки на HttpOnly cookie → новый пароль прошло успешно. Ошибки длины не погашают ссылку. После сброса прежняя сессия недействительна, новый пароль работает, старый отклоняется. Повтор сброса и повтор подтверждения адреса запрещены. Токены не переносились в отчёт.

После проверки сессия завершена. Два созданных для проверки QA-аккаунта и связанные записи удалены; другие аккаунты не изменялись. На снимках сохранены вымышленные данные до очистки.

Фактически проверено в Chrome на http://127.0.0.1:100/:

- Пустая отправка: три сообщения, резюме ошибок получает фокус, ссылки переводят к соответствующим полям. При одной ошибке фокус получает поле. Повторный переход из поля к ссылке другой ошибки работает; неизменившееся резюме не пересоздаёт ссылки при blur.

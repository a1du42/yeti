# Контракты компонентов

Все компоненты используют [токены](../../tokens.css) и правила [анимации](motion.md). Это спецификации, не готовые компоненты. После выбора стека использовать одну поддерживаемую систему доступных примитивов; не создавать собственные focus trap и keyboard navigation без необходимости.

## Общие состояния

| Состояние | Требование |
| --- | --- |
| Default | Видимая подпись, понятная граница действия |
| Hover | Работает только при поддержке hover, не открывает единственный путь к действию |
| Focus | Мгновенное кольцо; не меняет размеры |
| Pressed | Немедленная обратная связь, transform не двигает соседей |
| Disabled | Настоящая недоступность действия, нейтральные токены, понятная причина рядом |
| Loading | aria-busy, сохранённая геометрия, защита от повторной отправки |
| Error | Конкретная ошибка и восстановление рядом с источником |
| Success | Подтверждённый результат; не дублировать его лишним toast |

Применимость указывать по смыслу: у навигационной ссылки нет вымышленного success, у заголовка нет loading. Дополнительно нужны selected, expanded и read-only там, где это реальные состояния.

## Кнопки и ссылки

Высота от 44 px, отступы 16 px по горизонтали, gap 8 px, радиус 8 px. Одна основная кнопка на рабочую область. Основная: action / action-text с action-border 1 px. Вторичная: surface / text с control-border. Текстовая: link, без слабой границы «на всякий случай».

Hover меняет фон через короткий opacity-слой либо мгновенно; pressed масштаб 0,98 до 80 мс. Не добавлять hover-подъём всем строкам и карточкам. Focus не зависит от hover. Disabled использует muted и text-secondary вместо opacity всего элемента; не позволяет действие и не требует наведения для объяснения.

В загрузке сохранять ширину, например «Сохранить» → «Сохраняем…». Статический индикатор и подпись достаточны; бесконечный spinner не обязателен. Ссылка выполняет переход, button выполняет действие. Действия «Сохранить», «Отмена», «Закрыть» обычно без иконок; «Скопировать», «Скачать», «Добавить» могут иметь одну иконку.

## Поля и группы

Label над полем, gap 8 px, высота от 44 px. Border 1 px во всех состояниях. Placeholder только пример формата. Поле не заменяет label. Связать ошибку через aria-describedby и aria-invalid, обязательность обозначить текстом или знаком с пояснением.

Проверять впервые по blur или submit, затем перепроверять исправляемое поле. При неудаче сохранить введённое. Для нескольких ошибок дать фокусируемое резюме со ссылками на поля; иначе сфокусировать первое ошибочное поле. Не блокировать отправку без объяснения причины.

Справочные объяснения группы находятся у `?` рядом с её названием. Единицы, ограничения допустимого ввода, цена и ошибка остаются видимыми: это данные и условия, не скрытая справка. Read-only позволяет чтение и копирование, отличается от disabled.

## SectionHelp: знак `?`

Единый компонент для разделов и смысловых групп. Контракт: `label` (название раздела), `content` (краткое пояснение), устойчивый идентификатор связи; привязка к заголовку без вложения button внутрь ссылки.

- Визуальный знак 18 px, активная область 44 × 44 px; расстояние от названия 4-8 px с учётом реальных hit areas.
- Ширина тултипа до 320 px, на узком экране до ширины viewport минус 32 px; padding 12 px, радиус 8 px, текст 14/20 px.
- Токены help-bg / help-text / help-border; размещение сверху или снизу с автоматическим переворотом у края и отступом 8 px.
- Hover: задержка 240 мс, появление 120 мс. Focus: без задержки. Click, Enter, Space и tap открывают/закрывают справку без задержки.
- Escape закрывает; фокус остаётся на кнопке. Уход с кнопки на текст тултипа не закрывает его. Нет автозакрытия по таймеру.
- На touch закрытие повторным tap, касанием вне области или Escape с внешней клавиатуры. Одновременно открыт один тултип.
- Обычная справка не содержит ссылок и кнопок, не получает фокус: `role=tooltip`, триггер `aria-describedby`, доступное имя «Пояснение к разделу „Заказы“».
- Отложенные обработчики отменяются при уходе, переключении, unmount. Закрытая справка не остаётся интерактивным невидимым слоем.

Для длинной интерактивной инструкции нужен отдельный экран помощи или немодальная панель с корректной семантикой. Не выдавать такую панель за tooltip. Готовые тексты: [content.md](content.md).

## Навигация и вкладки

Sidebar: текущая ссылка имеет selected-фон, вес 500 и aria-current=page. Иконка 20 px + подпись. Переходы между маршрутами являются ссылками. Избранная зона не открывает навигацию других зон автоматически.

Вкладки для содержимого одного экрана: role tablist/tab/tabpanel, aria-selected, стрелки и Home/End. При дорогой подгрузке ручная активация Enter/Space; при мгновенной локальной смене допустима автоматическая. Не выдавать навигационные ссылки за ARIA tabs.

Короткие вкладки могут быть без иконок. При нехватке ширины использовать подписанный select или меню, а не исчезающие названия. Сохранять выбранный раздел и фильтры в URL, если это полезно для возврата и обмена ссылкой; секреты в URL исключены.

## Списки, таблицы и статусы

Настоящая table для сравнения по колонкам, список для самостоятельных объектов. Строка не ниже 52 px, padding 12-16 px; суммы выровнены вправо. Не делать всю строку кнопкой с вложенными кнопками: название содержит ссылку, действия вынесены отдельно.

Заголовок сортируемой колонки содержит кнопку и aria-sort; фильтры имеют подписи. Пагинация или серверное окно ограничивают объём. Виртуализация применяется после измерения и проверки доступности, а не по произвольному количеству строк.

Статус: короткая подпись, семантический цвет, при необходимости иконка. Не добавлять декоративную точку каждому пункту. Последнее обновление показывать, когда от свежести зависит решение.

Мобильный список оставляет название, статус, основной параметр и действие. Остальное доступно в деталях. Если сравнение требует настоящей широкой таблицы, разрешён явно подписанный локальный горизонтальный скролл с клавиатурой; страница в целом не скроллится по горизонтали.

## Диалог и боковая панель

Диалог до 512 px, padding 24 px (16 px на узком экране), радиус 16 px. Для самостоятельной большой формы открывать страницу. Панель до 448 px, на узком экране занимает доступную ширину.

Заголовок, при необходимости краткое описание, содержимое, действия. Фокус внутри, фон inert, видимая кнопка закрытия, Escape, возврат фокуса к триггеру. Начальный фокус по контексту: заголовок длинного текста или безопасное действие подтверждения. Не фокусировать разрушительное действие автоматически.

При несохранённых изменениях предложить сохранить или закрыть с потерей изменений. Не закрывать критичный процесс неявным нажатием на backdrop. Необратимое действие поясняет конкретный объект и последствия. Обратимое изменение может предлагать отмену только если backend действительно умеет её выполнить.

## Обратная связь

- Skeleton повторяет структуру и резервирует место. По умолчанию статический, без shimmer. При обновлении оставлять текущие данные и пометку обновления.
- Empty state: «Заказов пока нет» + одно действие «Выбрать услугу». Пустой поиск: «Ничего не найдено» + «Сбросить фильтры».
- Ошибка загрузки занимает сломавшийся блок и содержит «Повторить». Успешно загруженные блоки не исчезают.
- Временное уведомление не крадёт фокус, использует status/aria-live=polite. Не дублировать каждое сообщение несколькими live regions.
- Ошибки, требующие действия, не исчезают автоматически. Обычное уведомление может закрыться через 5 с с паузой на hover/focus; время чтения не является длительностью анимации.
- Графики добавлять только для утверждённых данных; подписи, единицы, легенда и табличная альтернатива обязательны. Значения доступны касанием и клавиатурой, не только наведением.

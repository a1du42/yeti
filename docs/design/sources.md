## Подключённый плагин

Motion MCP использован для поиска рекомендаций `transition duration reduced motion` и `animate duration ease`, получены ссылки на tween и easing. Точные параметры дополнительно сверены с [документацией animate](https://motion.dev/docs/animate). Код компонентов и платные ресурсы не запрашивались, пакеты не устанавливались.

При подготовке HTML-витрины дополнительно использован поиск Motion MCP по reduced motion и CSS-переходам. Для локальных документационных образцов достаточно CSS и Web Animations API: библиотека Motion не установлена, решение о стеке приложения остаётся открытым.

## Официальные материалы

- [Motion animate](https://motion.dev/docs/animate): длительность, easing и управление анимацией. Проектный выбор: tween для жёсткого лимита 800 мс.
- [WCAG: контраст текста](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): обычный текст 4,5:1, крупный 3:1. В проекте контраст вычислен по sRGB относительной яркости, не по светлоте OKLCH.
- [WCAG: нетекстовый контраст](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html): значимые границы и графика 3:1.
- [WCAG: контент по hover/focus](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html): возможность закрыть, навести и прочитать без самопроизвольного исчезновения.
- [WAI-ARIA Tooltip Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/): role=tooltip, aria-describedby, Escape, фокус на триггере. Сам паттерн помечен WAI как находящийся в работе; touch-поведение является отдельным проектным решением, а не заявленным требованием APG.
- Manrope и IBM Plex Sans остались в архивных ресурсах; актуальное семейство всего проекта по U14 — Rubik.
- [Rubik](https://github.com/google/fonts/tree/main/ofl/rubik): выбран близким аналогом нового образца логотипа, Bold 700; [описание](https://github.com/google/fonts/blob/main/ofl/rubik/DESCRIPTION.en_us.html) подтверждает скруглённые углы, [метаданные](https://github.com/google/fonts/blob/main/ofl/rubik/METADATA.pb) — кириллицу. Общий локальный variable WOFF2 получен из официального variable TTF ограничением диапазона до 400–700; исходный статический 700 использован для кривых логотипа; [OFL](assets/RUBIK-OFL.txt) сохранена. Точная идентификация шрифта растра не заявляется. Nunito Sans 800 остался только в архивном визуальном листе.
- [Phosphor](https://phosphoricons.com/): выбранная семья иконок; конкретный пакет зависит от будущего стека.
- [Официальные SVG Phosphor](https://github.com/phosphor-icons/core): исходники Regular встроены в HTML-витрину; [лицензия](assets/PHOSPHOR-LICENSE.txt) сохранена локально.
- [MDN: dialog](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog) и [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API): нативные механизмы диалога и верхнего слоя справки в документационной витрине.
- [Web Vitals](https://web.dev/articles/vitals): определения LCP, INP, CLS и оценка на p75. Числа в документах проекта являются целями будущего измерения.

## Разрешение противоречий навыков

Предел пользователя после уточнения составляет 800 мс; примеры навыков не заменяют проектные длительности. Параметры сведены в motion.md. Focus мгновенный, несмотря на общие советы анимировать все состояния. Ошибки и обязательные условия видимы, даже когда справочные пояснения находятся в tooltip.

Глобальный overflow clipping не используется как способ скрыть дефект адаптации. Равномерные строки таблицы допустимы. Семейства шрифтов имеют подтверждённую кириллицу. По U14 Rubik применяется во всём проекте: 400/500 для текста и управления, 600/700 для заголовков, 700 в логотипе. Белый текст CTA является документированным исключением из эстетического ограничения чистого белого.

Состав услуг и правила денег не выводятся из референса. Навыки не требуют добавлять встроенного ИИ-помощника в продукт. Текущий результат не проходил UI-проверки несуществующего приложения.

Архивные Manrope и IBM Plex Sans ранее извлечены из visual-spec.svg; в актуальной HTML-витрине они больше не подключаются. Эти файлы сохранены вместе с [OFL-лицензиями](assets/FONT-LICENSES.txt). Это документационные ресурсы; подключение и оптимизация шрифтов рабочей сборки будут рассмотрены после выбора стека.

При уточнении логотипа применён навык brand: единая композиция, правила версий, свободное поле, доступное имя и согласование источников. Новые проектные зависимости не добавлялись; fontTools и resvg использовались как временные внешние инструменты подготовки векторов и PNG вне проекта.
